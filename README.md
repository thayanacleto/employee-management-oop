# 💼 Sistema de Gerenciamento de Funcionários em Java
# 📌 Descrição

Este projeto implementa um sistema simples de cálculo de pagamentos utilizando Java e os princípios da Programação Orientada a Objetos.

A aplicação trabalha com dois tipos de funcionários:

Funcionário comum

Funcionário terceirizado

O cálculo do pagamento é feito de forma polimórfica, permitindo tratar todos os funcionários de maneira uniforme através de uma lista.

# 🧠 Conceitos aplicados

Programação Orientada a Objetos (POO)

Herança

Polimorfismo

Sobrescrita de métodos (Override)

Encapsulamento

Listas (ArrayList)

Entrada de dados com Scanner

# ⚙️ Funcionamento

O programa:

Solicita a quantidade de funcionários.

Pergunta se cada funcionário é terceirizado ou não.

Lê os dados (nome, horas trabalhadas, valor por hora).

Calcula o pagamento.

Exibe o valor final de cada funcionário.

Funcionários terceirizados recebem um adicional com acréscimo de 10%.
